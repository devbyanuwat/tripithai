# แหล่งอ้างอิงเนื้อหา

## หลักการ

TripiThai เป็น **layer ของการจัดระเบียบและสรุปเนื้อหา** — ไม่ใช่แหล่งต้นฉบับ
ทุกหัวข้อต้องลิงก์กลับไปยังแหล่งดั้งเดิมที่ผู้อ่านสามารถตรวจสอบได้

## แหล่งหลัก

### 1. พระไตรปิฎก ฉบับหลวง (เถรวาท)
- เว็บไซต์: **etipitaka.com**
- การเชื่อมต่อ: deep link อัตโนมัติจาก `ref` ของ frontmatter (parse เล่ม → URL)
- การใช้: link เท่านั้น ไม่ host เนื้อหา
- License: ฉบับหลวงเป็น public domain ในแง่เนื้อหา; layout ของ etipitaka เป็นของผู้พัฒนา

### 2. พุทธวจน — วัดนาป่าพง + มูลนิธิพุทธโฆษณ์
- เว็บไซต์: **watnapp.com**
- การเชื่อมต่อ: optional `watnapp` field ใน frontmatter (manual URL)
- การใช้:
  - **ปัจจุบัน:** deep link เท่านั้น
  - **เป้าหมาย:** ขออนุญาต quote เนื้อหาเป็น blockquote ใน MDX
    (ดู `docs/PERMISSION_REQUEST_WATNAPP.md`)
- License: ยังไม่ได้รับอนุญาตเป็นลายลักษณ์อักษร — ใช้เฉพาะ deep link

## หลักการอ้างอิง (citation policy)

ทุก quote ในเนื้อหาต้อง
1. **คงข้อความตามต้นฉบับ** — ห้ามดัดแปลงตัวอักษรหรือเรียงประโยคใหม่
2. **ใช้ `> blockquote`** ใน markdown
3. **บอกชื่อพระสูตร + ที่มา** ใน frontmatter หรือคำลงท้าย quote
4. **ลิงก์ต้นฉบับ** ผ่าน `etipitaka` หรือ `watnapp` field

ตัวอย่าง
```mdx
---
title: "อานาปานสติ ๑๖ ขั้น"
ref: "อานาปานสติสูตร ม.อุ. เล่มที่ ๑๔ ข้อ ๒๘๒"
watnapp: "https://watnapp.com/book/anapanasati"
---

## คำสอนตรงจากพุทธวจน

> "ภิกษุทั้งหลาย เมื่อบุคคลเจริญอานาปานสติให้มากแล้ว
> สติปัฏฐาน ๔ ย่อมบริบูรณ์..."
> — อานาปานสติสูตร
```
